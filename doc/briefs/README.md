# Briefs

A **brief** is the text forwarded to Claude Design before a new screen or a
substantially reshaped one is planned — the workstation's "design before
approval" rule. A screen's layout is cheap to argue over on a canvas and
expensive to argue over in a diff.

A brief that is not a design question still lives here: a capability the owner
asked for is written down before it is built, so the shape is agreed first.

- Write briefs as `UPPERCASE.md` in this folder.
- The handoff that comes back goes to `doc/handoffs/`.
- Once a brief has been forwarded it moves to `done/`, so this folder holds only
  what is still to be sent.
